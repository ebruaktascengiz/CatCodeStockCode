# CatCodeStockCode

This repository contains the CatCodeAI / SSC automation scripts and related utilities.

## Important

- Do not commit `.env` files or database credentials.
- Large generated files such as `.npy`, `.csv`, and local virtual environments are ignored by Git.
- Add your own environment variables locally before running the project.

## Setup

1. Create a virtual environment:
   python -m venv .venv
2. Activate it:
   .venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt
4. Add your environment variables in a local `.env` file.

## Push to GitHub

```bash
git remote add origin https://github.com/ebruaktascengiz/CatCodeStockCode.git
git branch -M main

```
